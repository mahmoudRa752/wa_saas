# WA SaaS Manager

WA SaaS Manager is a premium agent-centric live chat and team collaboration portal integrating Meta Cloud WhatsApp API to enable multi-agent support workflows, automated canned responses, bulk broadcasts scheduling, customer segmentation, performance monitoring, and audit logging.

## Core Feature Set

1. **Live Multi-Agent Chat**: Real-time WhatsApp web interface with visual SLA wait timers and unread badges.
2. **Employee Internal Chat**: Private secure messaging directory for employee-to-employee internal chat.
3. **Smart Filters & Customer Segments**: Save custom segmentation criteria combining Status, Assignees, and Tags.
4. **Scheduled Broadcast Campaigns**: Bulk scheduled dispatch campaigns with Excel spreadsheet contact lists parsing.
5. **Auto-Replies & Automation**: Keyword triggers and global responder rules.
6. **Collapsible Right-Hand Profile**: Active sidebar containing assignment controls, status selector, custom tag manager, notes log, and message statistics.
7. **Performance Analytics & Leaderboard**: Visual reports, employee leaderboard, message volumes, and response times charts.
8. **Advanced Search**: Query message transcripts, phone contacts, tags, and internal notes.
9. **Export Engine**: Export conversations to Excel spreadsheets or print/save high-fidelity PDF documents.
10. **Action Audit Logs**: Security event auditing system with pagination.

## Technology Stack
- **Core**: PHP 8.1+ / Apache / MySQL 5.7+
- **Frontend**: Bootstrap 5.3, Bootstrap Icons, Vanilla CSS, Chart.js
- **Integration**: Meta Graph API (WhatsApp Business Platform)
- **Dependencies**: PhpOffice (PhpSpreadsheet)
- **Containerization**: Docker & Docker Compose
